# Такси

## Запуск на компьютере

Установите Flutter stable с Dart 3.13.3 или новее и Chrome. Скачайте репозиторий и откройте его папку.

Откройте три терминала в корне проекта.

**1. Запустите сервер:**

```sh
dart server/bin/server.dart
```

**2. Запустите приложение клиента:**

```sh
cd taxi-customers
flutter pub get
flutter run -d chrome --web-port 8080 --dart-define=TAXI_API_URL=http://localhost:8081
```

**3. Запустите приложение водителя:**

```sh
cd taxi-driver
flutter pub get
flutter run -d chrome --web-port 8082 --dart-define=TAXI_API_URL=http://localhost:8081
```

Оба приложения откроются в браузере. Сервер оставьте работающим. Для карты и маршрутов нужен интернет.

## Запуск в GitHub Codespaces

1. Откройте репозиторий через **Code → Codespaces → Create codespace** и дождитесь установки Flutter.
2. Из корня проекта запустите сервер: `dart server/bin/server.dart`.
3. В панели **Ports** скопируйте HTTPS-адрес порта **8081**.
4. В двух новых терминалах запустите приложения командами ниже. Вместо `АДРЕС_API` вставьте скопированный адрес без слеша в конце.

Клиент:

```sh
cd taxi-customers
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080 --dart-define=TAXI_API_URL=АДРЕС_API
```

Водитель:

```sh
cd taxi-driver
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8082 --dart-define=TAXI_API_URL=АДРЕС_API
```

Откройте порты **8080** и **8082** в браузере через панель **Ports**. Если приложения не видят сервер, для демонстрации может потребоваться публичная видимость порта **8081**. У сервера нет авторизации: используйте только учебные данные и после демонстрации закройте доступ.

## Как пользоваться

**Клиент:**

1. Нажмите на адрес **А**, чтобы выбрать место подачи, и на **Б**, чтобы выбрать назначение. Можно выбрать место из списка или точку на карте.
2. Чтобы определить своё местоположение, нажмите кнопку с прицелом и разрешите доступ к геолокации.
3. Выберите тариф: **Эконом**, **Комфорт** или **Бизнес**. Цена появится рядом.
4. Нажмите **Заказать такси** и следите за статусом. До начала поездки заказ можно отменить.

**Водитель:**

1. Включите переключатель **Вы на линии**.
2. Выберите заказ в списке и нажмите **Принять заказ**. На карте появится маршрут к клиенту.
3. По прибытии нажмите **Я на месте**.
4. Когда пассажир сел, нажмите **Начать поездку**. Карта покажет маршрут до назначения.
5. В конце нажмите **Завершить поездку**.

Статусы обновляются у клиента автоматически. Завершённые поездки доступны в истории у обоих, заработок — в кабинете водителя.

При первом запуске в списке водителя есть три демо-заказа. Созданный клиентом заказ появится рядом с ними. Это учебное приложение: реальные машины не вызываются и деньги не списываются.
